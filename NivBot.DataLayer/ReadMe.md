# Datalayer for the GoodplaceBot

## Datachoices

There have not been made any datachoices for pure performance. Int for any numbers, long for Discord Snowflakes. etc.
In postgres the snowflakes have been converted to bigints.

## Database structure

The choice have been to reduce some features of the original bot. No more shop.
Besides this I have chosen not to comment in the datalayer models. Most of these are descriptive enough to show what is happening.
